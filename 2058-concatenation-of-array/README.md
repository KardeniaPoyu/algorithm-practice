# [1929. Concatenation of Array](https://leetcode.cn/problems/concatenation-of-array/)

**Difficulty:** Easy

Given an integer array `nums` of length `n`, construct an array of length `2n` whose first and second halves are both equal to `nums`.

## Solution

Python list concatenation directly produces the required two consecutive copies.

- Time complexity: `O(n)`
- Space complexity: `O(n)` for the returned array
