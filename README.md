# Algorithm Practice

Personal algorithm practice repository for LeetCode, Codeforces, AtCoder, and other online judges.

## Repository layout

```text
.
├── solutions/       # Manually maintained solutions
│   ├── leetcode/
│   ├── codeforces/
│   ├── atcoder/
│   └── others/
├── templates/       # Reusable contest templates
├── notes/           # Patterns, mistakes, and review notes
└── .github/workflows/verify.yml
```

LeetHub may create additional problem folders at the repository root. Those folders are managed by the extension and should not be renamed manually.

## File naming

- LeetCode: `0001-two-sum.py`
- Codeforces: `4a-watermelon.cpp`
- AtCoder: `abc350-a-past-abcs.py`

Each manually maintained solution should start with a short comment containing the problem URL, complexity, and key idea.

## Workflow

1. Solve the problem on the judge.
2. Let LeetHub or the platform-specific extension sync accepted submissions.
3. For manually added solutions, put the file under `solutions/<platform>/`.
4. Record reusable insights in `notes/patterns.md` and mistakes in `notes/mistakes.md`.

## Progress

| Platform | Solved | Target |
|---|---:|---:|
| LeetCode | 1 | 150 |
| Codeforces | 0 | 100 |
| AtCoder | 0 | 50 |

## Local checks

Python files are syntax-checked with `compileall`; C++ files are compiled individually with C++17 by GitHub Actions on every push.
